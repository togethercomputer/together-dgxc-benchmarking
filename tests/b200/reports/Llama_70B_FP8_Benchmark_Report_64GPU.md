## 1. Overview

## 5. Scripts

### 5.1 Sbatch Script

`pretrain_llama3_70b_fp8_cs_gpus64_tp1_pp1_cp1_vpNone_ep1_mbs1_gbs128_sbatch.sh`

```bash
#!/bin/bash
#
# Generated by NeMo Run (patched with NCCL/HF fixes)
#

# Parameters
#SBATCH --account=root
#SBATCH --exclusive
#SBATCH --job-name=root-root.pretrain_llama3_70b_fp8_cs_gpus64_tp1_pp1_cp1_vpNone_ep1_mbs1_gbs128
#SBATCH --mem=0
#SBATCH --nodes=8
#SBATCH --ntasks-per-node=8
#SBATCH --open-mode=append
#SBATCH --output=<log_dir>/sbatch_..._%j.out
#SBATCH --partition=batch
#SBATCH --time=00:30:00

set -evx

export PYTHONUNBUFFERED=1
export SLURM_UNBUFFEREDIO=1
export TORCHX_MAX_RETRIES=0

set +e

# setup
nodes=( $( scontrol show hostnames $SLURM_JOB_NODELIST ) )
nodes_array=($nodes)
head_node=${nodes_array[0]}
head_node_ip=$(srun --nodes=1 --ntasks=1 -w "$head_node" hostname --ip-address)

# PyTorch / NCCL
export TORCH_NCCL_AVOID_RECORD_STREAMS=1
export TRANSFORMERS_OFFLINE=1
export TOKENIZERS_PARALLELISM=False
export NCCL_NVLS_ENABLE=0
export TORCH_NCCL_HIGH_PRIORITY=1

# [PATCHED] Network interface pinning — required for this cluster
export NCCL_SOCKET_IFNAME=bond0
export GLOO_SOCKET_IFNAME=bond0
export NCCL_IB_HCA="=mlx5_0:1,mlx5_1:1,mlx5_4:1,mlx5_5:1,mlx5_6:1,mlx5_11:1,mlx5_14:1,mlx5_15:1"
export UCX_NET_DEVICES=bond0
export OMPI_MCA_btl_tcp_if_include=bond0

# [PATCHED] HuggingFace offline cache
export HF_HUB_OFFLINE=1
export HF_HOME=/mnt/vast/exemplar/llmb/.cache/huggingface

# NeMo / Megatron
export NEMORUN_HOME=/mnt/vast/exemplar/llmb/workloads/pretrain_llama3.1
export CUDA_DEVICE_MAX_CONNECTIONS=32
export NVTE_FWD_LAYERNORM_SM_MARGIN=16
export NVTE_BWD_LAYERNORM_SM_MARGIN=16
export PYTHONPATH=<megatron_bridge_scripts>:$PYTHONPATH

# Command 1
srun --output <log_dir>/log-..._%j_${SLURM_RESTART_COUNT:-0}.out \
  --container-image <squashfs_image> \
  --container-mounts <mounts> \
  --container-workdir /nemo_run/code \
  --wait=60 --kill-on-bad-exit=1 --mpi=pmix \
  --no-container-mount-home --container-writable \
  bash /nemo_run/scripts/pretrain_llama3_70b_fp8_cs_gpus64_...sh

exitcode=$?
set -e
echo "job exited with code $exitcode"
if [ $exitcode -ne 0 ]; then
    if [ "$TORCHX_MAX_RETRIES" -gt "${SLURM_RESTART_COUNT:-0}" ]; then
        scontrol requeue "$SLURM_JOB_ID"
    fi
    exit $exitcode
fi
```

## 6. Issues & Resolutions

During initial bring-up, four issues were encountered and resolved:

### Issue 1: Container Permission Error
- **Jobs affected:** 79092
- **Error:** `pyxis: mkdir: cannot create directory '/home/johnson': Permission denied`
- **Root cause:** Pyxis/enroot container runtime could not create user home directory on compute nodes when running as non-root.
- **Resolution:** Run job submission as `root` via `sudo`.

### Issue 2: NCCL Network Routing Failure
- **Jobs affected:** 79094, 79114
- **Error:** `socketPollConnect: connect to 7.247.226.120 returned No route to host`
- **Root cause:** Compute nodes have multiple network interfaces — `ens121f1np1` (7.247.226.x/23), `ens122f1np1` (7.247.227.x/23), and `bond0` (7.247.232.x/24). The host `/etc/nccl.conf` correctly sets `NCCL_SOCKET_IFNAME=bond0`, but this file is **not visible inside the container**. NCCL auto-selects `ens121f1np1`, which cannot route between nodes.
- **Resolution:** Added `NCCL_SOCKET_IFNAME=bond0`, `GLOO_SOCKET_IFNAME=bond0`, `NCCL_IB_HCA`, `UCX_NET_DEVICES`, and `OMPI_MCA_btl_tcp_if_include` as explicit exports in the sbatch script.

### Issue 3: Segfault on gpu-148
- **Jobs affected:** 79113
- **Error:** `Segmentation fault (core dumped)` during model initialization on `use3a-ss-b200-gpu-148`.
- **Root cause:** Suspected hardware issue on gpu-148.
- **Resolution:** Excluded gpu-148 from job allocation. Recommend moving this node to the `debug` partition for investigation.

### Issue 4: HuggingFace Cache Miss
- **Jobs affected:** 79117
- **Error:** `Cannot find the requested files in the disk cache and outgoing traffic has been disabled`
- **Root cause:** The sbatch script sets `HF_HUB_OFFLINE=1` but does not export `HF_HOME`. Inside the container, HuggingFace defaults to `~/.cache/huggingface` (empty) instead of the populated cache at `/mnt/vast/exemplar/llmb/.cache/huggingface`.
- **Resolution:** Added `export HF_HOME=/mnt/vast/exemplar/llmb/.cache/huggingface` to the sbatch script.

## 7. Recommendations

1. **Upstream the sbatch fixes** — Patch the NeMo Run / Megatron-Bridge sbatch template generator to include `NCCL_SOCKET_IFNAME=bond0`, `GLOO_SOCKET_IFNAME=bond0`, and `HF_HOME` by default for this cluster. These are missing from the auto-generated scripts.

2. **Triage gpu-148** — Move to the `debug` partition and run hardware diagnostics. It segfaults during model initialization.

3. **Validate remaining idle nodes** — Run an NCCL all-reduce benchmark across all 10 idle batch nodes to confirm they are healthy before larger-scale jobs.

4. **Container NCCL config** — Consider mounting `/etc/nccl.conf` from the host into the container (via `--container-mounts`) so that NCCL picks up the correct settings automatically.
